# net/netlink/genl/ — Generic Netlink Family Grammars

One file per generic-netlink family, plus the runtime registry. Each family file declares a `genl_cmd_grammar[]` (`{CMD, "name"}`) and `nla_attr_spec[]` tables (`{ATTR, NLA_KIND_*, size}`, mirroring the kernel's `nla_policy`), one for the family or one per cmd whose policy differs, packaged into a `struct genl_family_grammar`.

## Notes
- Wired by extern `struct genl_family_grammar fam_*` (declared in `include/netlink-genl-families.h`), collected by `families.c`. Adding a family = a new file here + a registry entry + the extern decl — link-time, no path coupling.
- `genl_family_rcv_msg()` looks the op up and tests its `GENL_ADMIN_PERM` / `GENL_UNS_ADMIN_PERM` flag before it parses a single attribute (`genl_family_rcv_msg_doit()`, or `genl_start()` for a dump), so a child that fails the test is answered `-EPERM` before the op's `nla_policy` runs. `GENL_ADMIN_PERM` is `netlink_capable(skb, CAP_NET_ADMIN)`, a test in the initial user namespace of both the socket's opener and the sender; `GENL_UNS_ADMIN_PERM` is the same test in the user namespace that owns the socket's netns. Family files name only which of their commands carry a flag.
- A cmd whose policy is not the family's, or whose handler needs attributes that its siblings' do not, carries its own table in `genl_cmd_grammar.attrs`, and `dump_attrs` for a dump request that draws from another. `genl_cmd_attrs()` picks it from the cmd in the body and the request's `NLM_F_DUMP`; a cmd with neither draws from the family's table. The genl core parses an op's attributes strictly unless the op opts out, so an id its policy has no slot for is answered `-EINVAL`, and a split op, or one at or past the family's `resv_start_op`, that has no policy gets a reject-all one: such a cmd names `genl_no_attrs` and is sent no attribute. `tests/genl_ops_test.c` mirrors the kernel policies of the families it lists and checks every generated request against its cmd's, nests and lengths included.
- A `NLA_KIND_NESTED` spec is never emitted empty: `append_specced_nested()` (`net/netlink/msg-attr-spec.c`) fills the container with one to three children, or up to the spec's `max_len` where the nest's parser takes no more (`S_NEST_MAX()` in the mirrors), one or two past it one draw in eight. They come from the spec's `nest` table, typed as the nest's own policy types it, or without one from the table the spec is in, whose ids belong to the outer policy and where a NESTED child is 16 placeholder bytes. Where the kernel recurses into a nest, each child is checked against the inner policy entry that shares its id: `nla_validate()` recurses only for `NLA_POLICY_NESTED` and `NLA_POLICY_NESTED_ARRAY`, and a bare `NLA_NESTED` is left to the handler's `nla_parse_nested*()` or hand-written walk, if it has one.
- `NLA_KIND_NESTED_ARRAY` is for `NLA_POLICY_NESTED_ARRAY`, whose children must be elements holding an attribute stream of their own. The container gets one to three elements, or up to the spec's `max_len` where the handler counts them against a cap (ovs_meter's BANDS, which `dp_meter_create()` holds to `DP_MAX_BANDS`, 1), going one or two past it one draw in eight; the mirrors in `tests/genl_ops_test.c` declare such a cap with `S_ARRAY_MAX()` and hold the counts to it as to a bound. The elements are numbered from 0 and flagged `NLA_F_NESTED` as a handler's `nla_parse_nested()` wants them, each holding one to three children from the `nest` table, which may name arrays in turn. A child that does not fit the window of a nest with a table is dropped, since a shortened one fails the policy; one without a table has its last child cut short to fill it.
- A u32 a genl policy bounds with `NLA_POLICY_MASK`, `NLA_POLICY_RANGE`, `NLA_POLICY_MAX` or `NLA_POLICY_MIN` is declared `NLA_KIND_U32_MASK`, with the policy's mask in `max_len`, or `NLA_KIND_U32_RANGE`, with its inclusive range in `min_len` and `max_len`: a MAX is a range from 0, a MIN one up to `UINT32_MAX`. A u32 that the handler bounds where the policy leaves it a plain `NLA_U32` (an ifindex that has to name a device, a version the handler accepts) is declared the same way, and its mirror slot gives the handler's bound. The genl policies read the word in host byte order, where the netfilter kinds that `nfnl/CLAUDE.md` describes are network order. `spec_fill_bounded()` (`net/netlink/msg-attr-spec.c`) draws a subset of the mask bits, or a number in the range, and leaves one draw in eight random bytes, so the policy's reject arm (`-EINVAL` for a mask, `-ERANGE` for a range) still sees traffic. `max_len` and `min_len` are `unsigned int` because a mask can use all 32 bits: nfsd's export flags are 18. The mirrors in `tests/genl_ops_test.c` say which slots are bounded (`S_U32_MASK()`, `S_U32_RANGE()`) and check that about seven draws in eight land inside the bound and that they span it, so a spec with a wider or a narrower bound than its policy's fails.
- A spec marked `.required = true` is an attribute its handler cannot do without: a `GENL_REQ_ATTR_CHECK()` or an `if (!attrs[X]) return -EINVAL` in a `pre_doit`, the doit, or the parser of the nest the attribute is in. The random draws pick a given attribute of a table of eight in about one request in three, so a handler with such a check returned early for most of them. `build_one_nlmsg()` therefore emits the marked specs of the cmd's table ahead of the random draws (`append_required_attrs()`, `net/netlink/msg-attr-spec.c`), each but one time in eight so the missing-attribute arm still sees traffic; the draws that follow can bring a left-out one back, so a request lacks it a little less often than that. A nest with a table of its own does the same for its marked children, in every element of an array; a child that no longer fits the window its nest shares with its siblings, 256 bytes at most, is dropped, marked or not, so a marked child deep in a message is in somewhat fewer of its nests. A nest without a table takes only the random draws, since the table it draws from is the outer policy's and its marks are the outer handler's. Only a table of several attributes needs a mark: a table of one is drawn from by every request that has any attribute. A mark cannot say "exactly one of" or "at least one of", which are left to the random draws. A spec marked `.once = true` is an attribute its handler refuses to see twice, as dpll's `*_ID_GET` lookups do: the random draws of a request never repeat one that went out already (`append_specced_nlattr()`'s `used` mask, top level only), and the mirrors mark it too, a stream that carries it twice failing. `tests/genl_ops_test.c` marks `.required` in the mirrors and checks that a marked slot is in at least 0.70 of the streams of its policy and not in all of them, and that every spec's mark, and its bound if it has one, is its mirror's.
- `cmd_caps[cmd]` holds the `GENL_CMD_CAP_DO` / `GENL_CMD_CAP_DUMP` bits of the `CTRL_ATTR_OPS` entry for that cmd, 0 when the reply left the cmd out or listed no ops. Every nested length is checked against the attribute enclosing it, and an op id past 255 (`genlmsghdr.cmd` is a u8) is dropped. `gen_genl_body()` hands the picked cmd's bits to `build_one_nlmsg()`, which sets `NLM_F_DUMP` to match; `tests/genl_ops_test.c` feeds a canned reply through `genl_resolve_families()` and checks both halves, and that most genl requests clear `genl_header_check()`'s flag and reserved tests.
